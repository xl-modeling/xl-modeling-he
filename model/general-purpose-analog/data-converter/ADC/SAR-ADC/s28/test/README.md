# S28 SystemC ADC 测试脚本

四个测试入口与场景十测试编号一一对应：

| 测试编号 | 脚本 | 激励与主要结果 |
|---|---|---|
| ADC-001-10-1-1 | `test/ADC-001-10-1-1.sh` | -1.10 V～+1.10 V 差分慢速斜坡；提取码0→1、码62→63跃迁并计算平均LSB |
| ADC-001-10-1-2 | `test/ADC-001-10-1-2.sh` | -1.10 V～+1.10 V 差分慢速斜坡；提取V1、V63并检查范围外饱和 |
| ADC-001-10-1-3 | `test/ADC-001-10-1-3.sh` | 0.95 V差分正弦，M=16384、k=147；统计DNL和INL |
| ADC-001-10-1-4 | `test/ADC-001-10-1-4.sh` | 对相干正弦输出码流做FFT；计算SNR、THD和ENOB |

运行全部测试：

```bash
python3 test/run_s28.py --all
```

单项测试直接运行对应编号脚本，例如：

```bash
bash test/ADC-001-10-1-1.sh
```

测试1初扫含512个电压间隔、513个电平，再对首末内部跃迁细扫，区间分辨率不大于0.01 LSB。四个编号脚本均默认开启VCD。

终端显示模型编译状态、测试用例、实测结果、通过状态及结果目录。完整运行日志保存在对应结果目录中。

MATLAB后处理运行方法见工程根目录 README.md。

构建目录按工程绝对路径自动区分；若指定的目录中留有其他工程的CMake缓存，脚本会选用独立目录，保留原缓存。编号入口和Python总入口使用同一规则。

测试3的C++统计与MATLAB报告统一采用观测到的首末有效跃迁作为端点；本次有效码为2～61、跃迁为2～62。该调整仅涉及采样后的指标计算。
